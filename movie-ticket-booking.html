🎬 Movie Ticket Booking System

C++ Qt OOP GUI File Handling

Overview

A desktop-based movie ticket booking application developed using C++ and Qt Framework. The system allows users to browse available movies, reserve tickets, manage booking history, and provides administrators with tools to manage movies and monitor reservations.

Objectives

  • Develop a complete desktop application using OOP concepts.
  • Implement secure user authentication.
  • Provide movie reservation functionality.
  • Create a dedicated admin dashboard.
  • Manage users and booking history efficiently.

Features

  • User Registration & Login
  • Movie Ticket Reservation
  • Booking History Tracking
  • Admin Authentication
  • Add Movies
  • Remove Movies
  • View User Reservations
  • File-Based Data Storage

Technologies Used

  • C++
  • Qt Framework
  • Object-Oriented Programming
  • GUI Development
  • File Handling

Challenges & Solutions

  • Challenge: Managing persistent data without a database.
    Solution: Implemented file-based storage for users, movies, and booking records.

  • Challenge: Separating user and administrator privileges.
    Solution: Implemented role-based access control.

Results

  • Successfully developed a functional desktop application.
  • Implemented authentication and booking workflows.
  • Applied Object-Oriented Programming principles.
  • Designed an interactive GUI using Qt Framework.
